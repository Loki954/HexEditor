## Version 1.8.11

- **Insert / delete whole lines** (16 bytes each), which change the file size:
  - **Insert line(s)** — right-click or the Edit menu; a small window asks how many lines and whether to add them above or below the current row. New lines are filled with FF.
  - **Delete line(s)** — removes the current row (or the rows your selection covers) and makes the file that much smaller.
  - Both are undoable with Ctrl+Z.
